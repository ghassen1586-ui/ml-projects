# Machine Learning Projects 🤖

Three machine learning notebooks built with Python and scikit-learn.

## Projects

### 1. Classification
Logistic Regression model with train/test split, confusion matrix, accuracy score, and model serialization with pickle.

### 2. Clustering
K-Means clustering with 3 clusters, centroid analysis, and scatter plot visualization.

### 3. Regression
Linear Regression model with RMSE and R² evaluation metrics.

## Tech Stack
- Python
- scikit-learn
- Jupyter Notebook
- pandas, matplotlib, pickle
